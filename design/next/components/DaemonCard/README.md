# DaemonCard

The sidebar footer showing the background daemon that keeps switch tools running: name, state, version, pid.

**The view provides:** running state, version, pid.

- All mono. A pulsing `live` dot and "Running" in `live-text`; stopped: `text-muted` dot and "Stopped".
- Click opens Settings › Daemons & Tools. Context menu: Restart Daemon, Copy PID, Show Log.
