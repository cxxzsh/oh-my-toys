# CategoryBadge

A tool's category as an uppercase pastel pill, one of eight fixed pairs.

**The view provides:** the category from the tool manifest; the label from i18n.

- `cat-<id>` on `cat-<id>-soft`, 11pt bold caps at 0.06em. Light System, Media, Network and Text sit at 3.9–4.3:1, so the label is never smaller or lighter.
- The UI colours tools by category, never by tool.
