# SegmentedControl

Two to four mutually exclusive options in a pill track; the chosen one rises as a white thumb.

**The view provides:** the options (one word each), the selection.

- Height `control-md`; track `fill-control` with `line-hairline`; thumb `thumb` / `on-thumb` with `shadow-xs`; labels in `caption`.
- One tab stop; ←→ move the selection and apply it at once.
- Theme (Auto · Dark · Light), duration presets. More than four options or long labels: a Select.
