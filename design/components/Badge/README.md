# Badge

A mono pill for counts and states next to a title or in a row ("12 Palettes", "6 active", "Active").

**The view provides:** text and tone.

- `badge` style. Tones: `neutral` (`fill-control`, `text-secondary`; add a `line-hairline` rim beside page titles) · `accent` (current selection, with a check glyph) · `success` · `warning` (Conflict) · `danger`.
- Status colour always comes with the word. Not interactive: a filter is a Chip.
