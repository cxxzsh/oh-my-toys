# SettingsList

Grouped settings rows in a card: glyph, title, description, and the control at the end.

**The view provides:** for each row a title, a one-line description and one control (Switch, SegmentedControl, Select, or a chevron to a sub-page).

- Row min height `settings-row` 44pt, padding `space-8` `space-16`, `line-hairline` between rows; title `body`, description `caption` in `text-inactive`; 16pt glyph in `text-secondary`.
- Settings apply at once: no Save or Apply button anywhere in Settings.
- One wording on every platform: "Launch at login", "Keep running in the background".
- Tab moves between the controls, not the rows.
