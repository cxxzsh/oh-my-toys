# Panel

A titled card that groups one tool's controls or one preview.

**The view provides:** title, glyph, tag, actions, content.

- `bg-card`, `line`, `radius-md`, padding `space-12`; title in `section` with an `accent` glyph; at most one primary button in its actions.
- Never nest panels; inside, use a DataTable, SettingsList or Sandbox.
