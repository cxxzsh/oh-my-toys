# Kbd

A keyboard shortcut, in tooltips, the palette and hints.

**The view provides:** the shortcut, written once with `Mod` for the primary modifier.

- **One definition, the OS's key names.** Shortcuts are defined once with `Mod` (⌘ on macOS, Ctrl elsewhere). The label follows the keyboard in front of the user: ⌘K, ⌥⌘K, ⌘↵ on macOS; Ctrl+K, Ctrl+Alt+K, Ctrl+Enter elsewhere. This is the only text that differs between platforms.
- `bg-button`, `line-control`, `radius-xs`, `kbd` style. In running text and footers use the plain hint style.
