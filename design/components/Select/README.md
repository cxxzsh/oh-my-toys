# Select

A pop-up button for one choice out of a list: shows the current value and opens a native menu.

**The view provides:** the options, the selection.

- Pill, `control-md`, min 120pt, `bg-button`, `line-control`, `shadow-xs`; value in `label`; trailing 14pt `unfold_more` glyph.
- Click, Space or ↓ opens the menu with the current item checked.
- Language, start-up behaviour, default duration. Two to four short options: a SegmentedControl.
