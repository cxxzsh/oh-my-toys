# Checkbox

An independent on/off option inside a tool panel, with its label.

**The view provides:** label, checked state, optional muted style for advanced options.

- 14pt box, `radius-xs`; checked: `accent-strong` fill, white tick. Label in `label` weight 400. The whole label is the hit target; Space toggles.
- In dark the white tick on `accent-strong` is 2.5:1, as in the source; the filled box carries the state.
- A setting that applies at once and stands alone in a row: a Switch.
