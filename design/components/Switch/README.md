# Switch

The on/off control of a switch tool, or of a setting that applies immediately.

**The view provides:** state and the label it belongs to.

- 38×22pt; compact 30×18pt in the tray panel and palette. White knob with `shadow-thumb`. Off: `text-muted` track; on: `accent-strong`. 150ms knob slide.
- Clicking the row's label toggles it too; Space toggles the focused switch.
- A switch tool reflects reality: if the OS refuses (permission, policy) the switch springs back and the row says why.
