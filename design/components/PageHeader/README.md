# PageHeader

The top of a tool's workbench: heading with count badges, one line of description, mono meta, and the filter row.

**The view provides:** title, badges, description, meta, chips and a hint.

- Heading `title`; description `caption` in `text-inactive`; meta in `meta`, values in `accent-text` or `success`.
- A `line` rule closes it with `space-12` below.
