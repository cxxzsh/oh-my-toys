# oh-my-toys

[English](README.md) | 简体中文

一盒顺手的桌面小工具。每个工具只做一件事，全部装在同一个应用里：主窗口、菜单栏 / 托盘快捷面板和命令面板。另有独立的命令行程序 `omt`，在终端里使用同样的工具。支持 macOS、Windows 和 Linux。

## 当前状态

应用和命令行 `omt` 已在本仓库。桌面应用：`go run ./cmd/oh-my-toys`。命令行：`go run ./cmd/omt`。macOS 上试用过。Windows 和 Linux 可以打包，但还没有在对应系统上跑过。还没有签名的发布版。

在 macOS 上，Cmd+Shift+A 截图。拖动时放大镜跟着指针；松开后，复制、保存和取消贴在选区上。回车复制，Cmd+S 把 PNG 存到 ~/Pictures/oh-my-toys，Esc 取消。截图是一个工具：打开它的页面就能开始截图，也能改保存文件夹。工具菜单里也有同一项。

## 计划中的工具

- **防睡眠**：让电脑保持清醒。可以选预设，也可以自己输入时长或截止时刻，还可以设一份每天的时间段计划，到点自动开启、到点自动关闭。
- **批量重命名**：按规则批量改文件名，修改之前先看预览。
- **找重复文件**：找出内容相同的文件，算出它们占了多少空间。
- **端口**：查看哪个进程占着端口，并一键释放。
- **颜色**：颜色格式互转，检查文字对比度。

之后还会加入更多工具。应用从一开始就为大量工具设计：搜索、钉住的工具和分类，能很快找到需要的那一个。

## 给脚本和 AI 用

不依赖屏幕的每个工具也可以通过命令行 `omt` 使用（支持 `--json` 输出），也可以用 `omt mcp` 给 AI 助手调用。目前 MCP 只提供只读操作和开关型工具；改文件或结束进程的操作还没有开放。截图只留在桌面应用里，因为它需要屏幕和人在现场。详见 [docs/agents.md](docs/agents.md)（英文）。
