# oh-my-toys

[English](README.md) | 简体中文

一盒顺手的桌面小工具。每个工具只做一件事，全部装在同一个应用里：主窗口、菜单栏 / 托盘快捷面板和命令面板。另有独立的命令行程序 `omt`，在终端里使用同样的工具。支持 macOS、Windows 和 Linux。

## 当前状态

oh-my-toys 正在从零重写。目前正在验证界面框架（[MyGo](https://github.com/egoist/mygo)，Go 语言），验证通过后才开始开发应用，所以暂时还没有可以安装的版本。

## 计划中的工具

- **防睡眠**：让电脑保持清醒，可以设定时长，也可以一直保持到手动关闭。
- **批量重命名**：按规则批量改文件名，修改之前先看预览。
- **找重复文件**：找出内容相同的文件，算出它们占了多少空间。
- **端口**：查看哪个进程占着端口，并一键释放。
- **颜色**：颜色格式互转，检查文字对比度。

之后还会加入更多工具。应用从一开始就为大量工具设计：搜索、钉住的工具和分类，能很快找到需要的那一个。
