# oh-my-toys

[English](README.md) | 简体中文

一盒顺手的桌面小工具。每个工具只做一件事，全部装在同一个应用里：主窗口、菜单栏 / 托盘快捷面板和命令面板。另有独立的命令行程序 `omt`，在终端里使用同样的工具。支持 macOS、Windows 和 Linux。

## 当前状态

应用和命令行 `omt` 已在本仓库。桌面应用：`go run ./cmd/oh-my-toys`。命令行：`go run ./cmd/omt`。macOS 上试用过。Windows 和 Linux 可以打包，但还没有在对应系统上跑过。还没有签名的发布版。

在 macOS 上，Cmd+Shift+A 截图。拖动时放大镜跟着指针；指针停在窗口上会框出整个窗口，单击就选中它。松开后工具栏贴在选区右下角：可以画箭头、马赛克和文字，再复制、保存或取消。回车复制，Cmd+S 把 PNG 存到 ~/Pictures/oh-my-toys，Esc 和右键逐级退出，Cmd+Z 撤销标注。截图是一个工具：打开它的页面就能开始截图，也能改保存文件夹。工具菜单里也有同一项。

抓包用来查看网络流量。代理模式下它在 127.0.0.1 上运行一个 HTTP(S) 代理，运行期间可以把它设为系统代理；信任它自己的根证书之后就能解开 HTTPS，查看请求和响应，过滤（一行搜索就能写 `host:`、`method:`、`status:`、`program:`、`type:`），用规则改写、伪造、拦截或延迟它们，重发某一条，并导出 HAR。每条流量都标明是哪个程序发起的：在侧栏点一个程序就只看它的流量，也可以让抓包只抓这个程序，其余的直接放行。忽略系统代理的程序（curl、许多 Go 和 Rust 程序）可以从抓包打开的终端里启动，那个终端已经设好了代理和证书变量。抓包模式下它读取一块网卡上的数据包（macOS 会请求管理员授权访问 /dev/bpf*，Windows 需要安装 Npcap）。停止抓包、退出应用，以及崩溃后的下一次启动，都会把系统代理还原。如果你的网络必须经过代理才能上网，请把那个代理设为抓包的上游代理。如果代理软件的虚拟网卡（例如 Surge 的）是你的主网络服务，macOS 会把那个服务的代理设置告诉应用，而不是抓包设置的那份，这时请自己把客户端指向 127.0.0.1 和端口。系统代理、证书和程序查找已在 CI 里的真实 Windows 和 Ubuntu 机器上测过，桌面应用本身也在 CI 里的 macOS、Windows 和 Ubuntu 真窗口中运行并截图验证。

## 计划中的工具

- **防睡眠**：让电脑保持清醒。可以选预设，也可以自己输入时长或截止时刻，还可以设一份每天的时间段计划，到点自动开启、到点自动关闭。
- **批量重命名**：按规则批量改文件名，修改之前先看预览。
- **找重复文件**：找出内容相同的文件，算出它们占了多少空间。
- **端口**：查看哪个进程占着端口，并一键释放。
- **颜色**：颜色格式互转，检查文字对比度。

之后还会加入更多工具。应用从一开始就为大量工具设计：搜索、钉住的工具和分类，能很快找到需要的那一个。

## 给脚本和 AI 用

不依赖屏幕的每个工具也可以通过命令行 `omt` 使用（支持 `--json` 输出），也可以用 `omt mcp` 给 AI 助手调用。目前 MCP 只提供只读操作和开关型工具；改文件或结束进程的操作还没有开放。截图只留在桌面应用里，因为它需要屏幕和人在现场；抓包也只留在桌面应用里，因为抓到的内容可能含有密钥，而且抓包会改系统代理。详见 [docs/agents.md](docs/agents.md)（英文）。
