# HomePage

主窗口首页"所有工具"：为几十上百个工具设计，先给最常用的，再给全部。

- **结构**（从上到下）：
  1. FilterChips：全部 + 各类别，带数量。
  2. `钉住`：用户钉住的工具，用 ToolCard（最多 8 个，一般 2 行内）。
  3. `最近使用`：最近打开的 4–8 个工具，用 ToolRow。
  4. 按类别分组的全部工具，用 ToolRow 紧凑网格。
- 选中某个类别时，只显示该类别的工具，不再显示"钉住"和"最近使用"。
- 搜索走侧边栏的搜索框或命令面板（⌘K），首页不重复放搜索框。
- 第一次打开、还没有钉住和最近使用时，这两节不显示，直接是全部工具。
- 预览里的 JSON 格式化、哈希计算、时间戳转换、截图识字、二维码、剪贴板历史是示例工具，用来演示工具很多时的样子，尚未实现。
