# ResultList

操作型工具的结果区：先列出将要发生的变化，底部一条汇总加执行按钮。对应命令行"默认只预览"的习惯。

- **使用方提供**：结果行（原值 → 新值，或表格列）、汇总文字、执行动作。
- 行用 `mono` 字体；原值 `text-secondary`，箭头 `text-tertiary`，新值 `text-primary`；有风险的行（覆盖、冲突）新值用 `warning` 并写明原因。
- 底部汇总：说清数量和当前是预览（`3 个文件将被重命名 · 预览，还没有修改任何文件`），右侧次要按钮"取消"和主按钮（动作 + 数量）。
- 有冲突时禁用主按钮，并在汇总里说明。执行完成后汇总改为结果（`已重命名 3 个文件`），用 `success`。
