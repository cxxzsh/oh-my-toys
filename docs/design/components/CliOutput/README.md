# CliOutput

`omt` 命令行的输出约定，以及在文档里如何展示命令行输出。GUI 里的每个工具都对应一个子命令。

- `omt` 是独立于桌面应用的命令行程序，和桌面应用共用同一套工具代码。一个工具一个子命令（`omt rename`、`dupes`、`color`、`ports`、`awake`），子命令和参数永远是英文。
- 给人看的输出跟随系统语言（中文或英文），简短、按列对齐，不带颜色代码；诊断信息写到 stderr。加 `--json` 时输出给程序读的固定格式，不翻译。
- 桌面应用在运行时，开关型工具的命令（如 `omt awake on`）交给桌面应用执行，托盘状态同步更新；桌面应用没运行时，`omt` 自己执行。
- **默认安全**：会改东西的工具先只预览（`rename` 加 `--apply` 才执行）；结束进程要确认 `[y/N]`，默认否，`--yes` 跳过。
- **最后一行是汇总**：说明数量和下一步，数量按语言的复数规则写：英文 `3 renames planned (dry run, nothing changed; pass --apply to execute)`，中文 `计划重命名 3 个文件（预览，未做任何修改；加 --apply 执行）`。大小用二进制单位（`KiB`）。结论用单词（`pass` / `FAIL`、`通过` / `失败`），不靠颜色也能看出来。
- GUI 的 ResultList 汇总文字与这里一一对应，共用同一份语言目录。
- 文档里展示输出时用 `mono` 字体放在卡片上；提示符和汇总行可用 `text-secondary`，通过 / 失败可用 `success` / `danger`。
