# ToolIcon

工具的图标：一个淡色圆角方块，中间是同色系的线条图形。颜色表示**类别**，不表示单个工具，所以工具再多也不会把颜色用完。

- **使用方提供**：工具的图形（从 Lucide 里选）和它所属的类别。
- **类别和颜色**：系统 `cat-orange`、文件 `cat-blue`、开发 `cat-purple`、网络 `cat-teal`、文本 `cat-pink`、媒体 `cat-green`、效率 `cat-indigo`；应用自身的项目（设置、所有工具）用 `cat-slate`。新增类别前先看能否归入现有类别；类别总数控制在 8 个以内。
- **区分同类工具靠图形**：同一类别的工具颜色相同，每个工具必须选一个不同的 Lucide 图形。
- **三种尺寸**：`icon-sm` 20px（侧边栏、托盘列表，圆角 `radius-icon-sm`）、`icon-md` 28px（卡片、列表行、托盘，`radius-icon-md`）、`icon-lg` 48px（工具页页头，`radius-icon-lg`）。
- 底色 `cat-<色>-bg`，图形 `cat-<色>`，线宽 2（Lucide 默认）。浅色下图形对底 3.9–5.7:1，深色下 4.4–6.2:1。
- 运行中的开关型工具可在右上角加 `success` 小圆点。
- **不要**：一个工具一个颜色；把类别色用在文字、按钮或大面积背景上；自己手画图形（统一用 Lucide，Mac 上可换成同形的 SF Symbols）；用 emoji。
