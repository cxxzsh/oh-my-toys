# WindowChrome

两个平台窗口外框的差异。品牌层（颜色、图标、布局、文案）两边一样，外框和系统材质跟随平台。

| | Mac | Windows |
|---|---|---|
| 窗口按钮 | 左上红绿灯，在侧边栏顶部 | 右上最小化 / 最大化 / 关闭，在工具栏右端 |
| 窗口圆角 | 系统决定（约 16px） | 系统决定（8px） |
| 侧边栏材质 | 系统侧边栏玻璃材质 | Mica Alt |
| 侧边栏顶部 | 红绿灯 | 应用名 |
| 字体 | SF Pro，正文 13px | Segoe UI Variable，正文 14px |
| 控件高度 | 28px | 32px |
| 快捷键写法 | ⌥⌘C | Ctrl+Alt+C |
| 托盘 / 菜单栏 | 菜单栏图标，面板向下弹出 | 通知区图标，面板向上弹出 |

- 两边的工具栏都放当前页面标题和页面级操作；不在标题栏里放菜单。
- 预览里的红绿灯颜色（`chrome-close` 等）只用于画图，真实应用由系统绘制。
