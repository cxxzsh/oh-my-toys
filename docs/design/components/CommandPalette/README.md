# CommandPalette

全局命令面板：在任何地方按快捷键呼出，输入几个字就能找到工具或直接执行工具的常用动作。工具数量多了以后，这是最快的入口。

- **呼出**：全局快捷键 ⌥Space（Mac）/ Alt+Space（Windows），可在设置里改；主窗口内也可用 ⌘K / Ctrl+K。托盘面板的搜索框是同一个搜索。
- **结果分两组**：`工具`（打开工具页）和 `动作`（工具声明的快捷动作，例如"防睡眠：保持 1 小时"）。匹配的字加粗；结果按匹配度和最近使用排序，最多显示 8 条。
- **搜索范围**：工具名、拼音和拼音首字母（`fsm` 能搜到防睡眠）、英文名、工具自己声明的关键词。
- **键盘**：↑↓ 选择，↩ 执行，⌘↩ / Ctrl+↩ 在主窗口打开，esc 关闭。动作可以有自己的快捷键，显示在右侧。
- **性能**：按键后 50ms 内出结果；搜索只读取工具的描述信息，不加载工具本身。
- 宽 600px，`bg-elevated`，`radius-xl`，`shadow-popover`；输入框 17px，结果行高 40px，选中行 `fill-selected`。
