# TrayPanel

菜单栏（Mac）/ 托盘（Windows）的快捷面板，代表整个 oh-my-toys。不管有多少个工具，面板大小都固定：只放正在运行的、钉住的，其余靠搜索。

- **结构**：
  1. **顶部**：搜索框（"搜索 N 个工具"，和命令面板同一套搜索，可以直接执行动作）+ 设置。
  2. **运行中**：只在有工具运行时出现，每个运行中的工具一行：图标、名字、实时状态、"停止"。没有就整节隐藏。
  3. **钉住的工具**：4 列启动格，最多 7 个钉住的工具 + 最后一格"所有工具"（打开主窗口首页）。运行中的工具右上角有 `success` 圆点。
  4. **底部**：打开主窗口（⌘O / Ctrl+O）、退出。
- **点击规则**：开关型工具点一下用上次的设置开 / 关；操作型工具打开主窗口对应页面；右键弹出该工具的快捷动作。
- **性能**：面板在点击后 100ms 内出现；只读取工具的描述信息和运行状态，不加载工具界面。
- 宽 `tray-width`，`bg-elevated`，`radius-xl`，`shadow-popover`，内边距 `space-3`。
- 图标见 TrayIcon；钉住哪些工具在 ToolManager 里设置。
