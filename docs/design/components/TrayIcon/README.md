# TrayIcon

菜单栏 / 托盘图标：来自 app 图标的四个小玩具（圆、方、三角、加号），单色。它代表整个 oh-my-toys，不代表任何一个工具。

- **两种状态**：平时是空心轮廓；只要有任何工具在运行，圆、方、三角三个形状变成实心。空心 / 实心在 16px 下也能一眼区分，不再额外加角标或换颜色。
- **Mac**：模板图（只用黑色加透明），系统会按菜单栏深浅自动反色；尺寸按 18pt 画。
- **Windows**：按任务栏深浅各出一版（白色 / 黑色），16、20、24、32px 各自绘制，不缩放。
- 文件：Icons 素材组的 `menubar.svg`（平时）和 `menubar-active.svg`（运行中）。
- **不要**：用某个工具的图标或颜色当托盘图标；按工具切换不同图标；用彩色。具体哪个工具在运行，看面板的"运行中"一节和鼠标悬停提示（例如 `oh-my-toys · 防睡眠运行中，剩余 2h29m`）。
