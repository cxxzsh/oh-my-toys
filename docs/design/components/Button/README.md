# Button

四种按钮：主按钮、次要按钮、文字按钮、危险文字按钮。

- **主按钮** `accent-fill` 底、`on-accent` 字：一个界面最多一个，放执行动作（`重命名 3 个文件`、`开始`）。文字写清楚会发生什么，带上数量。
- **次要按钮** `fill-control` 底、`text-primary` 字：选择文件夹、取消等辅助动作。
- **文字按钮** 透明底、`accent` 字：低频操作（`恢复默认`）。
- **危险文字按钮** 透明底、`danger` 字：不可撤销的操作（`结束进程`），点了要二次确认。
- 高 `control-height`（Windows 32px），圆角 `radius-md`，字重 600，左右 14px 内边距。焦点环 2px `focus-ring`，外扩 2px。禁用时 45% 不透明度。
- 打开设置窗口等会再出现对话框的动作，文字后加 `…`。
