# ToolCard

首页"钉住"区里的工具卡片：图标、名字、一句话说明、底部状态区。只给钉住的工具用；其它工具用更紧凑的 ToolRow。

- **使用方提供**：工具信息（名字、类别、说明、类型）和状态。
- **开关型工具**：底部左侧 StatusPill，右侧总开关，不进工具页也能开关。
- **操作型工具**：底部左侧一条最近状态（`上次：48 个文件`，没有就留空），右侧 `打开 ›`。整张卡片可点击。
- 右上角的图钉表示已钉住，点它取消。
- `bg-card`、1px `border-card`、`radius-lg`、`shadow-card`，内边距 `space-4`，最小高 132px。网格列宽至少 `card-min-width`，间距 `space-3`。
