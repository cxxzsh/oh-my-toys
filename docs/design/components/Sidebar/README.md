# Sidebar

主窗口左侧导航，为大量工具设计：搜索、钉住的工具、按类别折叠的分组。

- **结构**：搜索框（右侧提示 ⌘K / Ctrl+K）→ `所有工具` → `钉住`（用户钉住的工具，最多 8 个）→ 各类别分组 → 底部 `设置`。
- **每一项都有小方块图标**（20px ToolIcon，类别色）；`所有工具` 和 `设置` 用 `cat-slate` 方块。名字单行，过长时省略。
- **钉住的工具不在分组里重复出现**，避免同一个工具在侧边栏出现两次、两处同时高亮；分组标题右侧的数字是该分组里显示的工具数，没有工具的分组不显示。
- **分组可折叠**：分组标题左侧是折叠箭头。默认展开当前工具所在的分组，其它折叠；折叠状态会记住。
- **选中项**：`fill-selected` 灰色胶囊加粗。正在运行的工具右侧有 `success` 圆点。
- 工具很多时，侧边栏内容区可以滚动，搜索框和底部设置固定不动。工具列表用虚拟列表渲染，几百项也不卡。
- 宽 `sidebar-width`，底色 `bg-sidebar`（Mac 换成系统侧边栏材质，Windows 换成 Mica Alt），右侧 1px `separator`。
