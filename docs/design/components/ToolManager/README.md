# ToolManager

设置里的"工具"页：管理所有工具的启用、钉住和顺序。工具越多，这一页越重要。

- **每行**：ToolRow 的内容 + 类别名 + 钉住图钉（`accent` 表示已钉住）+ 启用开关。
- **顶部**：搜索框（"搜索 N 个工具"）和 `全部 / 已启用 / 已停用` 分段控件。
- **停用**：工具不加载代码、不占内存、不参与启动，也不出现在侧边栏、首页、托盘和搜索里；随时可以重新启用。正在运行的开关型工具被停用时，先停止它。
- **钉住**：最多 8 个，决定侧边栏"钉住"区、首页 ToolCard 和托盘面板的内容。拖动行可以调整钉住的顺序。
- 新安装的工具默认启用、不钉住。
