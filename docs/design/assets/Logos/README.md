# Logos

oh-my-toys 的 app 图标，1024×1024 SVG，浅色、深色各一版。

| 文件 | 用途 |
| --- | --- |
| `app-icon.svg` | 默认图标：白色圆角方块，浅色描边 |
| `app-icon-dark.svg` | 深色图标（macOS 深色图标、Windows 深色主题下的应用列表）：#1e1e21 圆角方块 |

- 四个小玩具按 2×2 排列，各用一个类别色：橙色圆（浅色版 #e8590c，深色版 `cat-orange` 深色值）、蓝色圆角方块、紫色三角、青色加号，意思是"一盒不同的工具"。浅色版的橙色比 `cat-orange` 浅色值更亮，因为这里是大面积色块，不是线条。
- 圆角方块的圆角约为边长的 22%，四周留白 100（共 1024），符合 macOS 图标网格；Windows 导出 .ico 时用同一张图。
- 菜单栏 / 托盘图标就是这四个形状的单色版（Icons 组）。
- 不要加渐变、投影或文字；不要改动四个形状的位置和颜色分配。名字用普通字体写 `oh-my-toys`，全小写、带连字符。
- 仓库里现在的 `AppIcon.ico` / `AppIcon.png`（蓝紫渐变）是旧版，需要按这里重新导出。
