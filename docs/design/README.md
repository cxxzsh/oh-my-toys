oh-my-toys 是一盒小工具：每个工具只做一件事，装在同一个应用里，有主窗口、菜单栏 / 托盘快捷面板、全局命令面板；另有独立的命令行程序 `omt`，和桌面应用共用同一套工具代码。现在只有几个工具，将来会有几十上百个，所以这套设计的每一处都按"工具很多"来定。先做 Mac 和 Windows，以后再扩展到其它平台。界面风格向 Mac 上做得好的工具类软件看齐（Surge、Lungo、iStat Menus），结构参考工具集合类应用（PowerToys、DevToys、DevUtils、Raycast）。浅色和深色同样重要，每个组件都要在两套主题下检查。

## 原则

- **应用是盒子，工具是主角。** 首页、侧边栏、托盘面板、命令面板都围绕"所有工具"组织。任何一个工具都不能占据应用级的位置：应用图标、托盘图标、窗口标题只代表 oh-my-toys。
- **为一百个工具设计。** 入口按"搜索 → 钉住 → 最近使用 → 按类别浏览"的顺序排；颜色按类别分配；固定大小的界面（托盘、侧边栏顶部）只放钉住的工具。
- **每个工具长得一样。** 统一的页头（ToolHeader）、两种页面模板（开关型、操作型）。界面由工具的描述信息自动生成，新增工具不改界面代码。
- **先预览，再动手。** 会改文件或结束进程的工具，先列出将要发生什么，点主按钮才执行，和命令行默认 dry-run 一致。
- **安静。** 一个强调色（`accent-fill`），只用在主按钮、开着的开关、焦点上。图标块用淡色类别色。不用插画、不用 emoji、不用渐变装饰。
- **两个平台，一套品牌。** 颜色、图标、布局、文案两边一样；窗口外框、系统材质、字体、快捷键写法跟随平台（见 WindowChrome）。

## 扩展到大量工具

**每个工具提供一份描述信息**，界面全部据此生成：

| 字段 | 说明 | 例子 |
|---|---|---|
| `id` | 稳定的英文标识，也是命令行子命令名 | `awake` |
| `name` | 名字，中英文各一份（中文 2 到 6 个字） | `防睡眠` / `Keep awake` |
| `summary` | 一句话说明，中英文各一份；写做什么，不写怎么做 | `让电脑保持清醒，不会因为空闲而睡眠` |
| `category` | 七个类别之一 | `system` |
| `kind` | `switch`（开关型）或 `action`（操作型） | `switch` |
| `icon` | Lucide 图标名 | `sun` |
| `keywords` | 额外的搜索词（同义词，中英文都可以） | `caffeinate, 不睡眠` |
| `actions` | 可在命令面板和托盘直接执行的快捷动作 | `保持 1 小时`、`关闭` |
| `platforms` | 支持的平台 | `macos, windows, linux` |

**类别**（颜色只按类别分配，类别总数控制在 8 个以内）：

| 类别 | 颜色 token | 现有工具 |
|---|---|---|
| 系统 | `cat-orange` | 防睡眠 |
| 文件 | `cat-blue` | 批量重命名、找重复文件 |
| 开发 | `cat-purple` | 颜色 |
| 网络 | `cat-teal` | 端口 |
| 文本 | `cat-pink` | — |
| 媒体 | `cat-green` | — |
| 效率 | `cat-indigo` | — |
| 应用自身 | `cat-slate` | 设置、所有工具 |

**入口如何随工具数量伸缩**：

- **命令面板**（⌘K / ⌥Space）：最快的入口，搜索工具名、拼音、拼音首字母、英文名、关键词，还能直接执行动作。
- **钉住**：用户最多钉 8 个；侧边栏"钉住"区、首页卡片、托盘面板都只显示钉住的工具，大小固定。
- **最近使用**：首页显示最近打开的 4–8 个。
- **按类别浏览**：侧边栏分组可折叠并显示数量；首页用 FilterChips 筛选、用紧凑的 ToolRow 列出全部。
- **停用**：工具管理里可停用不用的工具；停用的工具完全不加载。

**性能与稳定性要求**（实现时遵守）：

- **启动快**：应用只读取工具的描述信息；工具代码在第一次打开时才加载。
- **响应快**：托盘面板 100ms 内出现；命令面板每次按键 50ms 内出结果；超过 60 项的列表用虚拟列表。
- **互不影响**：一个工具出错时，只在它自己的页面显示错误，不影响其它工具和应用本身；开关型工具在后台独立运行，卡住时可以单独停止。
- **状态一致**：开关型工具的状态在主窗口、托盘、命令面板、命令行之间同步。

## 两类工具

| | 开关型 | 操作型 |
|---|---|---|
| 例子 | 防睡眠 | 批量重命名、找重复文件、端口、颜色 |
| 行为 | 打开后在后台持续生效 | 输入 → 预览 → 执行，一次性 |
| 钉住后在首页 | ToolCard：状态胶囊 + 总开关 | ToolCard：最近状态 + 打开 › |
| 托盘面板 | 点一下开 / 关；运行时出现在"运行中" | 点一下打开工具页 |
| 页面模板 | SwitchToolPage | ActionToolPage |

## 文案

**语气。** 直接、具体、口语化。说清楚会发生什么，以及例外。界面首发简体中文和英文两种语言（见下一节「多语言」）；下面的例子以中文为主，英文规范在本节末尾。

- 工具名用 2 到 6 个字的名词：`防睡眠`、`批量重命名`、`找重复文件`、`端口`、`颜色`。
- 一句话说明写"做什么"，不写"怎么做"：`按规则批量改文件名，先预览再执行`。
- 按钮写动作和数量：`重命名 3 个文件`，不要只写"确定"。会再弹出窗口的动作加 `…`。
- 状态用短语：`运行中`、`已关闭`、`运行中 · 剩余 2:29:10`、`3 个端口在监听`。
- 预览汇总写明还没修改：`3 个文件将被重命名 · 预览，还没有修改任何文件`。完成后：`已重命名 3 个文件`。
- 出错时说哪里不对，并给出正确例子：`格式不对：请输入 90m、2h30m 这样的时长，或 18:30 这样的时刻`。
- 命令面板里的动作写成"工具名：动作"：`防睡眠：保持 1 小时`。

**标点和数字（中文）。**

- 全角逗号、冒号、括号：`查找（正则）`。
- ` · `（前后有空格的间隔号）连接同一行里的几个事实。
- 数字和中文单位之间空一格：`30 分钟`、`3 个文件`；紧凑处用 `2h29m`。
- 时间：今天 `21:32`，明天 `明天 08:00`，更远 `11月7日 08:00`；倒计时 `2:29:10`。
- 快捷键：Mac 写 `⌥⌘C`，Windows 写 `Ctrl+Alt+C`。

**英文文案。**

- 句子式大小写（sentence case）：只有第一个词首字母大写，`Keep awake`、`Rename 3 files`，不写 `Keep Awake`。
- 按钮以动词开头并带数量：`Rename 3 files`、`Stop`；不用 `OK`、`Submit`。
- 不用感叹号，不写 `successfully`、`please`、`simply`。完成提示直接写结果：`Renamed 3 files`。
- 错误先说哪里不对，再给正确例子：`Use a duration like 90m or 2h30m, or a time like 18:30`。
- 标点用半角；中文的全角标点规则只用于中文。

## 多语言

- **首发语言**：简体中文（`zh-Hans`）和英文（`en`）。结构上可以继续加任何语言，不改界面代码。
- **源语言是英文**：每条文案先有英文原文和一个英文 key，中文是完整翻译；某种语言缺少某条翻译时回退到英文。
- **跟随系统**：默认使用系统语言，设置里可以手动切换。整个应用同一时间只显示一种语言，包括托盘面板、命令面板和系统菜单。
- **不写死文字**：界面上所有文字都来自语言目录，包括工具描述信息里的名字、说明、关键词和快捷动作名称。新增工具时，中英文必须同时提供。
- **给英文留空间**：英文通常比中文长 1.5 到 2 倍。设计和检查时用英文看最长的情况：按钮、胶囊、侧边栏项、托盘启动格里的名字过长时单行省略，不允许挤压，也不允许变成两行以上。
- **数量用复数规则**：英文写 `1 file`、`3 files`，不写 `file(s)`；中文没有复数，写 `3 个文件`。
- **日期、时间、数字按语言格式化**：中文 `11月7日 08:00`，英文 `Nov 7, 8:00 AM`；文件大小、小数点、千位分隔也随语言变化。倒计时 `2:29:10` 在两种语言下相同。
- **搜索不分语言**：不管界面是什么语言，工具的中文名、拼音、拼音首字母、英文名和关键词都能搜到。
- **字体**：`sans` 字体栈同时覆盖中英文：拉丁字母用 SF Pro / Segoe UI，中文落到苹方 / 微软雅黑，所以切换语言不需要换字体。
- **命令行**：子命令和参数永远是英文（`omt rename --apply`）；给人看的提示和汇总跟随系统语言（`LANG`、`LC_ALL`）；`--json` 这类给程序读的输出不翻译，格式固定。
- **文档**：仓库的 README 有中英文两份，内容保持一致。

## 颜色

- **底色层次**：窗口 `bg-window` → 侧边栏 `bg-sidebar` → 卡片 `bg-card` → 浮层 `bg-elevated`。深色主题靠底色变亮表现层次，不靠投影。
- **文字**：`text-primary` 写标题和正文；`text-secondary` 写说明、单位、分组名；`text-tertiary` 只用于占位文字、禁用状态和计数。
- **强调色**：`accent-fill`（主按钮、开着的开关）配 `on-accent` 文字；`accent` 用于文字链接、纯文字按钮、已钉住的图钉；`focus-ring` 用于键盘焦点。
- **状态**：`success`（运行中圆点、完成）、`warning`（会覆盖已有文件等提醒）、`danger`（错误、结束进程）。永远同时配文字或图标，不只靠颜色。
- **类别色**：`cat-<色>` 画图标线条，`cat-<色>-bg` 画图标淡色底。只用在 ToolIcon 和封面上。
- **控件**：分段控件、输入框、胶囊、次要按钮用 `fill-control`；悬停 `fill-hover`；侧边栏和列表选中 `fill-selected`；关着的开关轨道用 `border-control`，保证看得见。
- `chrome-*` 只用于在预览里画 Mac 红绿灯。

**对比度**：所有文字在它说明里写的底色上，浅色、深色都达到 4.5:1 以上；开关轨道、焦点环、图标线条（对它的淡色底）都达到 3:1 以上。已知取舍：`text-tertiary` 浅色只有 3.3:1，所以只用于占位、禁用和计数这类非必读内容。

## 字体与排版

- `sans` 字体栈：Mac 是 SF Pro，Windows 是 Segoe UI Variable，中文分别落到苹方和微软雅黑。标题和大数字用 `display`。文件名、正则、命令行用 `mono`。
- 层级：`large-title`（页面标题）→ `title`（卡片、面板标题）→ `headline`（设置项名、按钮、工具名）→ `body`（正文）→ `callout`（说明、单位）→ `eyebrow`（小标签、分组名）。
- 状态数字用 `numeric-xl`，等宽数字，后面跟 `callout` 单位。
- 一个页面只有一个 `large-title`。

## 间距、圆角、尺寸

- 4px 基础网格：`space-1` 4 … `space-10` 40。卡片内边距 `space-4`，网格间距 `space-3`（紧凑网格 `space-2`），页面区块间距 `space-6`，页面左右边距 `space-8`。
- 圆角由内到外逐级变大：控件 `radius-md`（8）→ 卡片 `radius-lg`（12）→ 面板 `radius-xl`（16）；分段控件里的滑块 `radius-sm`（6）。
- 图标块三种尺寸：`icon-sm` 20 / `icon-md` 28 / `icon-lg` 48，圆角约为边长的 23%（`radius-icon-*`）。
- 布局尺寸：侧边栏 `sidebar-width`，工具栏 `toolbar-height`，托盘面板 `tray-width`，工具页内容最大宽 `content-max-width`。

## 投影与动效

- 卡片只在浅色下有极轻的 `shadow-card`；托盘面板、命令面板和弹出菜单用 `shadow-popover`；开关圆钮和分段滑块用 `shadow-knob`。
- 动效只用于状态切换：开关、分段滑块、分组折叠 150ms 缓动。不做入场动画、不做循环动画。

## 图标

- **图形来源**：工具和界面图形统一用开源图标库 **Lucide**（ISC 许可，可商用，需保留许可声明）。24×24 网格、线宽 2、圆头圆角，一千多个图标风格一致，新工具从里面选一个还没被用过的。Mac 版可以换成形状相近的 SF Symbols，Windows 版继续用 Lucide；同一界面里不混用两套。
- **工具图标**：Lucide 图形放在类别色的淡色方块上（ToolIcon）。侧边栏里每一项都有方块，`所有工具` 和 `设置` 用 `cat-slate`。
- **界面图形**：搜索、设置、箭头、文件夹、警告等，颜色跟随文字，16px（`glyph`）。
- **菜单栏 / 托盘图标**：四个小玩具（圆、方、三角、加号）组成的单色图标，代表整个应用。平时是空心轮廓；有任何工具在运行时，圆、方、三角变成实心。Mac 作模板图；Windows 按任务栏深浅出白 / 黑两版（见 TrayIcon）。
- **app 图标**：白色（深色版为深灰）圆角方块，四个小玩具用类别色（Logos 素材组）。暂定，以后再改。
- 不用 emoji。

## 平台适配

| | Mac | Windows |
|---|---|---|
| 字体 | SF Pro / 苹方，正文 13px | Segoe UI Variable / 微软雅黑，正文 14px |
| 控件高度 | 28px（`control-height`） | 32px |
| 侧边栏 | 系统侧边栏玻璃材质，红绿灯在顶部 | Mica Alt，应用名在顶部 |
| 窗口按钮 | 左上红绿灯 | 右上最小化 / 最大化 / 关闭 |
| 快捷面板 | 菜单栏图标，向下弹出 | 通知区图标，向上弹出；右键是系统菜单 |
| 命令面板 | ⌥Space（可改） | Alt+Space（可改） |
| 快捷键写法 | `⌘` `⌥` `⇧` 符号 | `Ctrl+Alt+Shift` 文字 |

颜色、间距、圆角、图标、文案在两个平台上完全相同。

## 组件

基础：ToolIcon、StatusPill。控件：Button、Switch、SegmentedControl、TextField、FilterChips。导航：Sidebar、CommandPalette。首页：ToolCard、ToolRow、HomePage。工具页：ToolHeader、MetricTile、SettingsList、ResultList、SwitchToolPage、ActionToolPage。设置：ToolManager。托盘：TrayPanel、TrayIcon。平台：WindowChrome。命令行：CliOutput。

预览是静态 HTML，用 `components/bundle.css` 和这里的 tokens 画出来，用来定样子和规则；真实应用分别用各平台的控件实现。预览里的 JSON 格式化、哈希计算、时间戳转换、截图识字、二维码、剪贴板历史是示例工具，用来演示工具很多时的样子，尚未实现。

## 说明

- 这是新方向的设计，还没有落到代码里。现有的 Windows 应用（`apps/windows`）仍是 Fluent 风格、只有防睡眠，托盘图标还是太阳，都需要按这里重做。
- 没有字体文件：SF Pro、Segoe UI Variable、苹方、微软雅黑都由系统提供。
- Lucide 图标的许可声明见 Icons 素材组。
